Project Overview & Model Specifications

Viva Quick Reference

🤖 Model Architecture

Random Forest Classifier with 100 estimators, max depth 8, and Gini impurity criterion. Evaluated against Logistic Regression & Decision Trees.

📊 Dataset & Split

1,000 synthetic records across 6 domains (Academic, Work, Health, Finance, Personal, Social). 80% Train (800) / 20% Test (200) Stratified Split.

⚙️ Preprocessing Pipeline

Numerical features normalized via StandardScaler; categorical attributes encoded via OneHotEncoder with unseen category tolerance.

🎯 Engineering Value

Solves Reminder Fatigue by replacing dumb static timers with adaptive urgency scoring, dynamic sound alarms, and context-aware frequency.

🔊 Adaptive Audio Alert Demonstration

Traditional reminder apps use identical chimes for all alerts. Smart Reminder differentiates acoustic profiles using the Web Audio API based on the predicted priority tier:

🚨 High Urgency

Pulsing siren (880Hz / 660Hz) with rapid cadence.

⚠️ Medium Urgency

Harmonic bell chime (587Hz -> 880Hz).

✅ Low Urgency

Soothing ambient pop (440Hz decaying bell).
